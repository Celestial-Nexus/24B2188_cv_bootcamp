## Run order (all from the `code/` directory)

```bash
cd code/

# Task 1 + Task 2 training (runs 1 and 2; saves per-epoch logits for T2)
python task1.py

# Task 2 analysis (reads saved logits — no GPU needed)
python task2.py

# Task 3 (runs 3–7: 5-fold CV)
python task3.py

# Task 4 (runs 8–11: SCE, co-teaching, filter+retrain)
python task4.py

# Task 5 (runs 12–13: synthetic label retraining)
python task5.py

# Generate results.json
python make_results.py
# Then fill in: name, roll_no, gpu_used in results.json

# Validate submission
cd ..
python check_format.py <rollno>_cv_bootcamp.zip
```

## Definitions

### `train_acc_mislabeled` (in `predictions/t2_dynamics.csv`)
Accuracy of the network's predictions on the **mislabeled subset** of the training set
(samples where `noisy_label ≠ clean_label`), measured **against the noisy label**.
This rises as the network memorizes the wrong annotations — the memorization signal.
Measured in eval mode, no augmentation. Scale: 0–100 (percentage).

### Memorization start epoch
First epoch E (1-indexed) such that a 3-point centered moving average of
`train_acc_mislabeled` exceeds its minimum over the first 5 smoothed values by 5 pp,
and stays above that threshold for 3 consecutive smoothed points.
Cross-checked against `val_acc_clean` peak (must be within ±2 epochs).

### Co-teaching predictions (`predictions/t4_co_teaching.csv`)
Averaged softmax of **both** networks → argmax. If one network's val accuracy at
epoch 60 differs from the other by more than 5%, use the better network alone
(this case is documented in `logs/t4_co_teaching_log.json` if it occurs).

### Task 5 method choice
Task 5 always uses a self-contained method (SCE or co-teaching — whichever won
Task 4 among those two). `filter_retrain` is excluded from Task 5 because it would
require new noise-score computation on `synthetic_label`, consuming the 5-run
Task 3 budget. This decision is made a priori and recorded in `logs/t4_best.json`.

### Task 3 signal choice
Signal chosen **a priori**: 5-fold OOF CE loss (`-log p(noisy_label)`) combined
with logit-space margin (`z_best_other - z_noisy`), rank-normalized 0.6/0.4.
No class-wise normalization — per-class noise rates span 28% (horse) to 51.5%
(cat, deer); per-class normalization would equalize unequal rates and hurt
precision@k.
AUROC against clean labels is computed post-hoc in `logs/task3_analysis.json`
for analysis only and does not influence any training or filtering decision.

### Final epoch convention
All `t1_*`, `t4_*`, `t5_*` prediction CSVs use the **final epoch (60)** model.
`t2_early_stop.csv` uses the epoch with highest `val_acc_noisy` (noisy validation
labels only; ties broken by earlier epoch).

## Reproducibility notes
- Global seed: 42 (torch, numpy, random, CUDA). Set at the top of each task script.
- Normalization statistics computed from the 45k training split only (not val).
- GPU-side augmentation: raw uint8 padded with 0 before normalizing (border ≈ -2.0
  after norm); random crop offsets sampled independently per image (not per batch).
